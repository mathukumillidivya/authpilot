      Accuracy on the 100 development cases, by round

      The first multi-agent design lost to a single call.

      Each round started by reading the failures one by one and asking whether the model had misjudged something, or had simply miscounted or misread a code. Judgement stayed with the model. Bookkeeping moved to code.

        Let the model read. Let code count.

        Each step is a node in a LangGraph graph. The patient record is reached through an MCP server in front of a FHIR store, the way an agent would reach a hospital's records. Blue steps are AI agents. Green steps are plain code.

          One rule, one specialist

          A specialist judges a single rule against the whole record. A single call has to juggle every rule at once, and it mixed them up.

          Code does the arithmetic

          Models miscount days. Code dates every record against the order, checks every time window, and sends a wrong count back to the specialist once.

          No quote, no finding

          A finding counts only if its quote is really in the record, with the same numbers and dates. Not one test denial went out without verified evidence.

          Search before asking

          When a rule is undocumented, an investigator searches the record again through MCP tools before the system asks the doctor for more.

          What this does not show

          • The cases are constructed.There is no public benchmark for prior authorization, because real requests contain patient data. The 300 cases were generated with known answers from real Medicare rules. Real requests are messier: scanned faxes, missing pages, conflicting notes.
          • The records are short.About 70 entries per patient. Real charts can run to thousands of pages. A long-record version exists, but it costs about four times as much to run and was not part of the test.
          • The case design changed during development.Three case templates were ambiguous and were rewritten, and date and procedure checks moved into code. The 200 test cases were run once, after the system was frozen.
          • Five policies, one model.Other services and other models may behave differently.
          • A clinician signs every denial.This is decision support. It drafts the determination and shows its evidence. It does not send denials on its own.
